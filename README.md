## About

This 75-minute module helps you use GenAI to support real-world financial forecasting workflows. You’ll learn how to prompt for trend detection and scenario planning, and how to evaluate GenAI outputs with a critical business lens.

## Content

| Lesson | Est. Delivery Time | Skills |
| ------ |:------------------:| ------ |
| [Mapping workflows to AI tasks](./microlesson-01/README.md) | 20 min | Workflow decomposition, AI task mapping |
| [Prompting GenAI for forecasting](./microlesson-02/README.md) | 20 min | Structured prompting, trend and scenario generation |
| [Mini lab: Evaluate AI forecasts](./microlesson-03/README.md) | 35 min | Forecast generation, validation, and business critique |
| **Total content** | 75 min |  |

### Prerequisites

- Experience reading financial statements or metrics
- Familiarity with spreadsheet tools (Excel, Sheets)
- Comfort using GenAI to analyze or summarize data
